Use this guide to learn the observed path. Items marked with low or unknown confidence require confirmation from an experienced owner.

- **Goal:** Prepare the reviewed report for the weekly operations meeting

## Guided walkthrough

### Lesson 1: Open the source

- **Do:** Open the dated CSV in the spreadsheet editor
- **Why:** Establish the review period before filtering
- **Use:** Spreadsheet editor
- **Start with:** Source CSV
- **Look for:** Open review sheet
- **Evidence:** HIGH (92%) — Repeated in the observed session

### Lesson 2: Review exceptions

- **Do:** Filter rows marked for follow-up and add notes
- **Why:** Separate items that need an owner decision
- **Use:** Spreadsheet editor
- **Start with:** Open review sheet
- **Look for:** Reviewed report
- **Evidence:** LOW (32%) — Partial evidence only

## When the path changes

- **Ask:** Does the row have a follow-up marker?
- **Observed answer:** Add it to the reviewed report
  - If No marker → Leave the row unchanged
  - **Evidence:** MODERATE (68%) — Observed once
- **Variation: Missing source date** — when The export has no date in its filename: Ask the operations owner to confirm the review period before continuing
  - **Evidence:** LOW (32%) — Partial evidence only
